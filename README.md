# Personal Finance Tracker

A console-based Java application designed to help users track their income, expenses, and overall financial management securely.

## Features
* User Authentication: Secure login system with credential verification.
* Income & Expense Tracking: Add, view, and manage financial transactions easily.
* Financial Management: Monitor account balances and transaction history.
* Object-Oriented Design: Built using core OOP principles including encapsulation, inheritance, polymorphism, and abstraction.

## 🛠️ Tech Stack
* **Language:** Java
* **Development Tool:** Visual Studio Code
